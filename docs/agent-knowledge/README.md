# Geobooker Agent Knowledge Pack

Fecha de preparacion: 2026-09-10

## Objetivo

Este paquete contiene documentos publicos y comerciales preparados para cargar en Meta Business Agent - Knowledge Files y para reutilizar como base controlada del chatbot web/PWA de Geobooker.

No contiene secrets, tokens, datos personales de leads, bases CSV, contratos privados ni informacion interna sensible.

## Regla operativa

- Subir solo documentos vigentes y revisados.
- Retirar versiones obsoletas antes de subir versiones nuevas de precios, paquetes, Premium, politicas o beneficios.
- No subir CSV de prospectos, datos de CRM, tokens, PIN, claves de Meta, Supabase Secrets, service role, contratos privados ni informacion legal confidencial.
- Usar estos documentos tambien como fuente base del chatbot PWA para mantener coherencia entre web, CRM y WhatsApp.

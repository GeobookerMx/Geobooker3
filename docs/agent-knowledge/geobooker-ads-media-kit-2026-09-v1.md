# Geobooker Ads - Media Kit

Version: 2026-09-v1
Estado: vigente para knowledge publico/comercial

## Resumen

Geobooker Ads es la oferta publicitaria de Geobooker para ayudar a negocios y marcas a ganar visibilidad dentro del ecosistema Geobooker.

## Modalidades de publicidad

- Visibilidad local.
- Campañas por ciudad o zona.
- Campañas regionales.
- Campañas nacionales o internacionales, sujetas a inventario, cumplimiento y operacion.
- Sponsored content.
- Perfiles premium o destacados, cuando esten disponibles.
- Paquetes B2B gestionados mediante Geobooker Leads / Connect.

## Segmentacion posible

- Pais.
- Estado.
- Ciudad.
- Zona.
- Categoria de negocio.
- Industria.
- Tipo de cliente objetivo.
- Idioma.
- Producto o servicio de interes.
- Nivel de prioridad comercial.

## KPIs recomendados

- impresiones;
- clics;
- CTR;
- leads creados;
- contactos iniciados;
- respuestas;
- reuniones solicitadas;
- oportunidades creadas;
- propuestas enviadas;
- ingresos atribuidos cuando exista trazabilidad suficiente.

## Lo que si se puede prometer

- planeacion de campaña;
- segmentacion comercial;
- ejecucion controlada;
- seguimiento;
- reportes;
- optimizacion gradual;
- medicion razonable segun canal y permisos disponibles.

## Lo que no se debe prometer

- ventas garantizadas;
- reuniones garantizadas;
- entregabilidad universal;
- resultados identicos en todos los paises;
- uso de WhatsApp sin consentimiento;
- acceso o venta irrestricta de bases de datos.

## Siguiente paso comercial

Cuando una empresa o agencia pregunte por campañas, se debe registrar interes comercial y pedir datos minimos:

- empresa;
- pais o mercados objetivo;
- industria;
- objetivo;
- presupuesto estimado o rango;
- periodo deseado;
- persona de contacto;
- canal preferido.

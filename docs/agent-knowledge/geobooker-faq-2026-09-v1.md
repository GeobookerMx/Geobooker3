# Geobooker - FAQ oficial

Version: 2026-09-v1
Estado: vigente para knowledge publico/comercial

## Que es Geobooker?

Geobooker es una plataforma para encontrar, registrar y promocionar negocios. Tambien esta evolucionando hacia soluciones comerciales para publicidad, leads y seguimiento empresarial.

## Registrar mi negocio es gratis?

Geobooker puede ofrecer registro gratuito y funciones premium segun disponibilidad, promociones y configuracion vigente. Para evitar informacion desactualizada, el usuario debe revisar la pagina oficial o contactar a Geobooker para confirmar beneficios actuales.

## Donde descargo Geobooker?

La pagina oficial de descarga es:

https://geobooker.com.mx/download

Desde ahi se debe orientar al usuario hacia la opcion disponible para Android, iOS o PWA segun corresponda.

## Geobooker sirve para publicidad?

Si. Geobooker Ads permite preparar campañas de visibilidad para negocios, marcas y empresas, con enfoque territorial, por categoria y por objetivos comerciales.

## Geobooker puede hacer campañas internacionales?

La arquitectura de Geobooker permite preparar campañas por pais, ciudad, region, idioma, industria y tipo de negocio. Las campañas deben cumplir reglas de consentimiento, privacidad, politicas de plataforma y disponibilidad operativa de cada mercado.

## Cuanto cuesta anunciarse?

Los precios pueden variar por paquete, alcance, pais, ciudad, inventario, duracion, segmentacion, volumen y nivel de servicio. Si el usuario pregunta precios, se debe ofrecer una revision comercial o enviar informacion vigente aprobada.

## Puedo hablar con una persona?

Si. Cuando un usuario pida hablar con una persona, se debe registrar una solicitud de handoff humano y canalizarla al equipo de Geobooker.

## Como dejo de recibir mensajes?

Si una persona escribe BAJA, ALTO, STOP o una solicitud equivalente, se debe respetar como opt-out y registrar la preferencia para no enviar comunicaciones futuras por ese canal.

## Geobooker puede revelar tokens, claves o secretos?

No. Geobooker nunca debe revelar Meta App Secret, WhatsApp Access Token, Supabase service role, PIN, credenciales, claves privadas ni informacion interna sensible.

# Geobooker - Guia oficial de registro de negocios

Version: 2026-09-v1
Estado: vigente para knowledge publico/comercial

## Objetivo

Ayudar a negocios a crear presencia en Geobooker de forma clara, ordenada y segura.

## Que puede registrar un negocio

Un negocio puede registrar informacion publica y comercial como:

- nombre del negocio;
- categoria;
- descripcion;
- direccion o zona de atencion;
- telefono publico;
- sitio web o redes sociales;
- horarios;
- fotos publicas;
- servicios principales.

## Beneficios del registro

- Aparecer dentro del ecosistema Geobooker.
- Facilitar que clientes encuentren el negocio.
- Mejorar la presencia digital del negocio.
- Preparar el perfil para posibles herramientas premium o publicitarias.
- Centralizar informacion publica que ayude a usuarios a decidir.

## Proceso recomendado

1. Crear cuenta o iniciar sesion.
2. Registrar el negocio con datos correctos.
3. Completar la mayor cantidad posible de campos publicos.
4. Subir fotos reales y autorizadas.
5. Revisar que telefono, direccion y horarios sean correctos.
6. Esperar validacion o revision cuando aplique.

## Buenas practicas

- Usar informacion verdadera.
- No usar marcas, fotos o textos sin autorizacion.
- Mantener horarios y canales de contacto actualizados.
- Responder a clientes de forma profesional.

## Notas sobre Premium

Premium y promociones deben comunicarse solo con informacion vigente y aprobada internamente. Si un precio, periodo gratis o beneficio no esta confirmado, el agente debe invitar al usuario a contactar a Geobooker o consultar la seccion oficial correspondiente.
